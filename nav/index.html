如何新增專案

本頁面所有內容都來自同一個資料檔 projects.json；新增或修改專案只需編輯該檔，不需要改動本頁程式碼。

欄位說明：name 專案名稱、description 簡介、stack 技術堆疊（陣列）、 status 狀態（已上線 或 開發中）、category 分類、url 連結（相對路徑）、 updated 更新日期（YYYY-MM-DD）、highlights 亮點（陣列，可省略）。

{
  "id": "new-project",
  "name": "新專案名稱",
  "description": "一句話簡介。",
  "stack": ["HTML", "CSS", "JavaScript"],
  "status": "開發中",
  "category": "工具",
  "url": "new-project/",
  "updated": "2026-10-24",
  "highlights": ["重點一", "重點二"]
}

分類清單可於 categories 欄位自訂；若未提供，會自動由各專案的 category 彙整。

本頁為單一 HTML 檔，執行時讀取同目錄的 projects.json；若以本機檔案方式開啟（file://）而無法讀取， 會改用內嵌於本頁的備份清單，並在頁首標示資料來源。
